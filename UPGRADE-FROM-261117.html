如果你还在 1.68.261117

这个版本的更新按钮有缺陷，无法自动升级。下面是解决办法。

!问题是什么

1.68.261117 的「检查更新」能检测到新版本，但点「下载并应用更新」会报错：

没有可下载的更新包

原因是读取下载地址时字段名写错了，拿到的地址永远是空的。这个错误在已经发布出去的文件里，无法远程修复。

不是你的网络问题，也不是你的操作问题。是代码本身的缺陷。

1解决办法：手动下载覆盖

这是最快的方式，两分钟搞定：

  1. 在浏览器打开本项目的 Releases 页面
  2. 找到最新版本 ENC-V1.68.261118（正式版）
  3. 下载对应版本：
    • ENcwork-otto-1.68.261118.html — 完整版（Win10+）
    • ENcwork-legacy-1.68.261118.html — 精简版（Win7 也能用）
  4. 用它覆盖你现在使用的 HTML 文件
  5. 重新打开即可
好消息：261118 之后，更新功能已经彻底重写，以后在应用内就能一键升级了。

2261118 修了什么

  • 更新系统全部重写 — HTML 单文件优先下载，5 条检测线路自动切换，下载后真正生效
  • 新增远端公告 — 以后有重要消息会直接弹出来，就是你现在看到的这个功能
  • 修复主界面网格 — 应用缩放时卡片被压扁的问题

注意：261118 是补丁版，不包含新功能。新功能（作业编辑器全屏、设置页布局重构等）在 1.69-beta3 里，需要切到「预发行版」通道。

3升级之后

到 261118 或更新版本后，更新流程就正常了：

  1. 设置 → 数据管理 → 检查更新
  2. 点「检查更新」
  3. 发现新版后点「下载并应用更新」
  4. 刷新页面即生效
