挂在教室大屏上的作业板。

一个 HTML 文件，双击就能开。作业、考勤、考试倒计时、节假日、时钟全在一屏里，数据只存在你自己的浏览器，不联网、不上传、不用注册。

---

## 为什么做这个

晚自习前，课代表在黑板上抄作业。粉笔灰、涂改、字迹潦草、擦不干净，后排同学眯着眼也看不清写的是哪科。

后来想，教室那块大屏天天亮着，为什么不用它。

于是有了 ENcwork：把黑板上的东西搬到屏上，字号可调、内容可改、不用擦。

## 能干的事

**作业**
点卡片写，`Ctrl + Enter` 存。支持 Markdown、快捷词、模板、图片、标签、完成标记。边写边自动存草稿，手滑关掉也不丢。

**考勤**
点卡片点名，出勤 / 迟到 / 请假 / 缺勤四种状态，名字颜色随便改。名单能整班粘进去，支持中文、全拼、首字母搜（打 `zs` 出张三）。有周报月报，能导 CSV 和 PNG。

**倒计时**
考试时间表、节假日、周末都能自定义。精度可以只到天，也可以精确到分。

**考试看板**
单独的全屏页面，不占主界面。大字时钟 + 当前科目 + 考试时间范围，四种样式可选，「影院」那套是深底单列、时钟能显示到毫秒。字号能用滑杆拉。

**Live2D 背景（完整版独占）**
把你自己的 Live2D 模型放上去当背景。支持导入多个模型并存、动作列表随机、按时间自动换动作、参数手动调、跟随触摸转视线。默认关闭，不吃性能。

**其他零碎**
通知公告、作业历史、作业量统计、学习热力图、本地快照（留 10 份可回滚）、数据体检、导出 JSON / MD / PDF、自动备份、截图、实时运行日志、检查更新。

**问 AI**
不需要 API Key。选好数据范围，它把统计口径整理成一段提示词，复制到豆包 / ChatGPT / Claude 那边问就行。

## 一些细节

- **数据在哪**：全在浏览器 localStorage 和 IndexedDB 里。换电脑、换浏览器都不带过去，想搬就用「导出数据」。
- **会不会丢**：有草稿自动保存 + 本地快照 + 可选自动备份到文件夹。三重保险，但还是要偶尔导出一次 JSON，别赌。
- **怎么更新**：设置 → 关于 → 检查更新。从 1.68.1 起默认下载 `.ENC` 更新包，自动校验并应用，不用手动换文件。也可以选发行版或预发行版通道。
- **能不能离线**：第一次要联网拿依赖库，之后就有缓存了。

## 附加资源包

程序本体之外，有两个独立的包按需下载：

### 主题资源包（约 83MB）

邦多利 / 世界计划主题的角色卡面与立绘。**仅完整版可用**。

👉 **[下载主题资源包](https://github.com/kausmi/ENcwork/releases/tag/ENC-Theme-Pack)**

导入方式：切到「邦多利」或「世界计划」主题 → 设置 → 数据管理 → 卡面资源包管理 → 导入资源包（选 zip，不要解压）。

内含 40 个邦多利角色 + 26 个世界计划角色的卡面与表情贴图。不导入不影响其他功能，只是这两套主题没有卡面背景。

### Live2D 引擎包（约 240KB）

1.68.1 起，Live2D 运行时从程序本体剥离成独立的**引擎包**（约 240KB）。这样程序本体小了一截，引擎也能单独升级。

👉 **[下载 Live2D 引擎包](https://github.com/kausmi/ENcwork/releases/tag/ENC-Engine-5r5)**

首次用 Live2D 需要先导入引擎：设置 → 数据管理 → Live2D 引擎 → 选择 `ENC-L2D-Engine-5r5.zip`（不要解压）。导入一次长期有效，不用重复导入。

引擎包支持 **Cubism 5**（moc3 v5 / v6），比之前的版本能多认一批新模型。
