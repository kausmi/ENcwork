# ENcwork（E课作业）双版本介绍文档

> **ENcwork · 月行水上** —— 专为晚自习场景打造的教室大屏作业展示板
> 单文件 · 离线可用 · 数据本地存储 · 无需安装

本文档基于对两个源文件的逐行静态分析编写，所有结论均可在源码中定位。分析基准：文件内版本日志最新条目为 **2026-10-10**。

---

## 一、这是什么

ENcwork 是一个**运行在浏览器里的教室大屏作业看板**。把一个 `.html` 文件拷到教室电脑上双击打开即可使用：

- **各科作业**一屏铺开，学生抬头即看
- **考勤人数**、**考试倒计时**、**节假日倒计时**、**时钟**同屏展示
- 所有数据保存在**本机浏览器**里，**不联网、不上传、不注册**

它面向的真实场景是：老师每天在黑板上写作业太费事，学生也记不全；用一块大屏把当天各科作业统一展示出来。

> 版本命名规则（源码注释）：`0.x → 月影`、`1.x → 月行水上`、`2.x → 浮生听梦`、`3.x → 月华流转`、`4.x → 夕阳之下`。当前处于 **1.x「月行水上」** 阶段。

| 对比项 | **精简版**（LITE EDITION） | **OTTO版**（OTTO EDITION） |
|---|---|---|

| 系统要求 | **Win7 / Win8 / Win10 及以上** | **Win10 及以上** |
| 老电脑 / 旧版 Edge | 可正常运行（内置 ES5 垫片） | 不支持 |

| JS 函数声明 | 541 个 | 613 个 |
| 内嵌图片 | 5 张（同一图标的 5 次重复） | 27 张（含联动主题素材） |
| 内嵌 base64 体积 | 约 477 KB | 约 1.46 MB |
| 装饰性特效 | 已整体替换为兼容桩 | 完整可用 |
| 邦多利 / 世界计划主题 | 无 | 有（8 乐队 + 6 组合） |
| 视频 / GIF 背景 | 无（仅静态图与渐变） | 有 |

## 三、如何选择

- **教室电脑是 Win10/Win11，配置正常** → 选 **OTTO版**。主题更多、特效更全、能换视频背景。
- **电脑较老、系统是 Win7/Win8，或只有旧版 Edge** → 选 **精简版**。它专门为老环境做了 ES5 语法垫片与 CSS 兼容层。
- **不确定**：先用精简版跑通，需要更多外观再换 OTTO版，数据可以直接搬。

## 四、核心功能（两个版本都有）

### 4.1 作业管理

- 点击学科卡片 → 打开编辑弹窗 → 输入内容 → **Ctrl + Enter 保存**
- 编辑区支持 **Markdown**：标题、粗体、斜体、删除线、代码、引用、有序/无序/任务列表、表格、分割线、高亮、上下标、链接、图片
- 顶部**快捷词**标签一点即插入常用语句（背诵／默写／练习册／预习／复习／订正／抄写／朗读／试卷／笔记，可自行增删）
- **作业模板**：常布置的内容存成模板，一键插入
- **插入图片**：本地上传（存 IndexedDB，正文里以 `encdb:<id>` 引用）或链接上传
- **图片卡片**：添加学科时输入「图片」二字即可创建纯图片卡片，支持预览、更换、移除
- **作业标签**：自定义名称与颜色，打上标签后卡片按标签色显示
- **完成标记**：作业项可标记完成，已完成的自动沉底
- **草稿保护**：编辑中内容自动留存（0.6 秒防抖），不会误丢
- **整理卡片**：拖拽排序；卡片右上角菜单可改学科颜色、重命名、删除学科
- **学科自定义**：名称、颜色、图标（内置图标库或上传本地图片／GIF）

### 4.2 日期与切换

- Dock 栏 **← / →** 按自然日逐天切换（空日期也能翻）
- 点**日历**按钮任选一天，使用自制的日历选择器
- 键盘 **← / →** 同样可切换
- 每天打开自动跳到**当天**

### 4.3 复制到班级群

Dock 栏点**复制** → 把当前查看日期的全部作业转成纯文本 → 在 QQ/微信群 **Ctrl + V** 粘贴。

### 4.4 考勤管理

- 主界面考勤卡片显示**应到 / 实到**大数字，未出勤学生姓名以标签列出
- 点卡片弹出点名窗：逐个点学生选状态（默认 **出勤 / 迟到 / 请假 / 缺勤**，状态名称与颜色可自定义）
- **批量标记**：弹窗右上角进入多选 → 底部操作条一键套用状态
- **名单管理**：少量学生用输入框（逗号/空格/分号分隔），全班名单粘贴到「批量导入」（每行一人）
- **拼音搜索**：支持中文姓名、拼音全拼、首字母缩写（输入 `zs` 匹配「张三」），显示「匹配 X / 共 Y 人」
- **分组管理**：可按小组整组设状态
- **考勤报表**：按本周/本月/自定义范围汇总每人出勤、迟到、请假、缺勤次数及出勤率，可导出 **CSV**（Excel 直接打开）或 **PNG**

### 4.5 考试与节假日

- **考试时间表卡片**：名称、日期、时间段；显示倒计时
- **节假日卡片**：支持自定义节假日，显示倒计时
- **周末倒计时**：起止日可配置
- 倒计时精度可切换：仅天数 / 天+小时 / 天+时+分

### 4.6 通知与公告

- 设置 → 布局与内容 → **通知与公告**（或顶栏铃铛）
- 填写标题与内容，类型选**普通通知**或**紧急通知**（红色高亮）
- 顶栏下方出现通知条，横向滚动最多展示 5 条
- 铃铛显示**未读数角标**，点击查看详情并自动标记已读
- **正文支持 Markdown 渲染**

### 4.7 作业历史与统计

- Dock 栏点**时钟图标**打开作业历史
  - **日历视图**：有作业的日期显示小圆点
  - **列表视图**：按日期倒序，点击展开/收起
  - 支持**学科筛选** + **关键词搜索**，可「跳转到该日期」
- **作业量统计**：本周/上周/本月/上月/自定义范围，横向柱状图 + 数据表格，显示各科作业项数及占比，可导出 **CSV / PNG**

### 4.8 问 AI · 数据分析

无需任何 API Key，**纯本地生成提示词**：

1. 设置 → 其他 →「问 AI · 数据分析提示词生成器」
2. 选择模式：**作业数据分析** 或 **考勤数据分析**
3. 选择范围：仅当天／最近 7 天／最近 30 天／自定义／全部数据
4. 点「生成提示词」→ 点「一键复制」→ 粘贴到豆包/ChatGPT/Claude 等对话窗

AI 会识别「学科名 + 作业项」结构，把每一条作业项独立计数（统计口径为「项」，不合并、不漏计）。

### 4.9 截图

- Dock 栏点**截图**（完整作业内容）→ 输出干净版图片
- 输出格式：PNG / JPEG / 剪贴板（可选）
- 可选择是否包含图片卡片
- 支持缩放倍率，超大画布按 8192 px 上限自动收缩
- **双引擎自动降级**：优先 `snapdom`（能正确渲染 `color-mix` 与毛玻璃），失败或超时自动回退 `html2canvas`

### 4.10 数据管理

**导出**
- 导出 JSON（完整备份）
- 导出 MD（当日作业为 Markdown 文件，含学科分组与完成标记）
- 导出 UAF（统一作业文件格式，PDF）
- 多日期导出 JSON（可全选／近 7 天）
- 自定义导出：勾选要导出的板块（作业／考勤／外观／其他）

**导入**
- 导入 JSON
- 导入 UAF（从 UAF 格式 PDF 解析作业内容——基于文本层与坐标聚类识别学科标题、按列归属，**不是 OCR**）

**自动备份**（需 Chrome / Edge）
- 选择备份文件夹并授权 → 勾选启用 → 选间隔（5 分钟 ~ 24 小时）
- 未选文件夹时降级为浏览器下载方式
- 可从备份文件夹扫描并选择性恢复

**数据快照**
- 手动/自动快照，最多保留 10 份，可回滚
- 可导出为**单文件 HTML 快照**离线保存

**运行错误日志**
- 自动捕获页面 JS 报错与未处理的 Promise 异常，最多保留 100 条
- 一键复制完整日志（含类型、时间、信息、位置、完整堆栈）

**危险操作**
- 清除图片缓存（仅删无引用图片）
- 清空今日作业
- 清空所有数据（需多次确认）

### 4.11 应用自更新（更新数据包）

把当前应用的功能代码打包成一个「更新数据包」分发；别人导入后**原地升级**。

- 只打包功能代码，图片等资源不随包分发（导入时自动从当前版本恢复）
- 使用 gzip + base64 压缩，体积远小于原文件
- **不会重置**作业、考勤与各项设置数据
- 也可「导出应用 HTML」直接得到一份完整的可运行文件

### 4.12 外观与布局（共同部分）

- **字号**：字号自适应屏幕（默认开启），或手动拖滑块（14 ~ 48 px）+ 整体缩放（50% ~ 200%）
- **字体**：系统字体列表，或上传自定义字体
- **背景**：上传本地静态图、或使用图片链接、或选内置渐变预设；可调模糊度、颜色遮罩、显示方式（铺满/完整显示/拉伸/居中/平铺/固定视差）、裁切位置；支持多图轮换
- **背景归属**：通用背景（所有主题共用）或当前主题专属
- **卡片布局**：三种布局引擎（1.0 经典怀旧单列 / 2.0 原始简单 / 3.0 智能平衡瀑布流）、卡片间距、圆角
- **Dock 栏自定义**：勾选网格逐个显示/隐藏 Dock 按钮
- **界面元素**：顶栏、时钟、秒数、考勤卡片、考试卡片、节假日卡片等显隐

### 4.13 其他

- **快捷键**：`Ctrl + /` 查看全部
- **一键全屏**（适合大屏展示）
- **超低性能模式**（闪电按钮，一键关闭所有特效）
- **系统错误检测**：检测数据完整性、DOM 元素、核心功能
- **性能分析器**：自动/手动分析帧率、帧率波动、CPU 占用，给出设备性能等级（15/30/60/120 秒可选）
- **新手教程**：首次打开自动引导，可在「设置 → 关于」重新查看
- **设置搜索**：输入关键词（如「考勤」「字号」「问 AI」）快速定位设置项

## 六、精简版 的特点

精简版不是「少几个功能的 OTTO版」，而是**为老环境专门做的一版**：

1. **ES5 兼容垫片**：源代码中内嵌了一段纯 ES5 垫片（`Array.prototype.includes/find/findIndex`、`String.includes/startsWith`、`Object.assign/entries`、`Number.isNaN` 等），并移除了全部 ES6+ 可选链语法，避免旧版 Edge(EdgeHTML) 整段脚本报错。
2. **CSS 兼容层**：为不支持 `color-mix()`、`inset` 简写、`flex gap`、`backdrop-filter` 的浏览器提供静态实色回退。
3. **移除全部装饰性特效**：液态玻璃、卡片边缘高光/泛光、背景粒子、超华丽plus 快捷栏等，在精简版中已整体替换为**空实现**（源码注释明确说明「仅保留性能分析器用于诊断」）。
4. **仅保留 5 套 Material 主题**：紫罗兰 / 蔚蓝 / 苔绿 / 碧青 / 暗色。
5. **体积约为 OTTO版 的 61%**，启动更快、内存占用更低。

## 七、两版数据互通

两个版本**共用同一份浏览器本地数据**（同一 localStorage 键），因此可以在同一台电脑的同一个浏览器里互相搬运：

1. 在**旧版本**里点「导出我的数据到中转槽位」
   （位置：设置 → 反馈与帮助 → 数据迁移，或新手教程最后一步）
2. 打开**另一个版本**，点「从另一版本导入」
3. 勾选要覆盖的板块（学科作业 / 标签 / 快捷词 / 考勤 / 考试 / 节假日）→ 确认导入

- 全程**不联网、不产生中间文件**
- 导入会**覆盖**本版本对应数据，建议先导出一份 JSON 备份
- 另有「清空中转槽位」

## 八、技术架构

### 8.1 依赖（两个版本完全相同）

| 库 | 版本 | 用途 |
|---|---|---|
| `pinyin-pro` | 3.27.0 | 名单拼音搜索（全拼 + 首字母） |
| `@zumer/snapdom` | 3.1.0 | **首选**截图引擎 |
| `html2canvas` | 1.4.1 | 截图**回退**引擎、UAF 渲染 |
| `jspdf` | 2.5.2 | UAF PDF 导出 |
| `pdfjs-dist` | 4.2.67 | UAF PDF 导入解析 |
| Google Fonts | — | `Space Grotesk` + `IBM Plex Mono` |

**无框架、无打包器、无构建流程。** 全部 5 个库都有运行时存在性检查，缺失时自动降级（截图退到 html2canvas、拼音退到纯文本匹配、PDF 相关提示库加载中）。

> 注：依赖通过 CDN 加载，因此**首次打开需要联网**加载这几个库；之后浏览器缓存可用。界面背景等资源均为本地内嵌。

### 8.2 存储

| 层次 | 内容 |
|---|---|
| **localStorage** | 主数据 `homework_board_v5`；通用背景兜底；错误日志；版本互导中转槽位；各类开关与偏好（约 22 个键） |
| **IndexedDB** | 5 个数据库：`HomeworkBoardDB`（背景图/字体/备份目录句柄）、`enc_snapshot_db`（快照）、`enc_image_store`（作业正文图片）、`enc_asset_pack_db_v1`（卡面资源包），OTTO版另有 `enc_pack_db_v2` |

主数据 JSON 结构（节选）：

  "currentDate": "YYYY-MM-DD",
  "subjects": [ { "id": "sub_math", "name": "数学", "icon": "📐",
                  "color": "#3A86FF", "order": 0, "homework": {} } ],

### 8.3 值得称道的工程细节

- **瀑布流布局 3.0**：Flex 列容器 + LPT 贪心分列 + 二次平衡，列高更均匀；测量期临时关闭 `content-visibility` 以取得真实高度
- **Markdown 后台渲染**：把同一份渲染源码经 `Function.prototype.toString()` 序列化进 Blob Worker，只预热 500 字以上未缓存文本，结果与主线程一致
- **内存水位保护**：每分钟检测 JS 堆用量，>70% 轻度清理、>85% 深度清理，**只动可再生缓存，用户数据永不触碰**
- **虚拟滚动**：卡片 ≥ 14 张时自动启用 `content-visibility`
- **统一帧调度**：全应用单一 `requestAnimationFrame` 主循环，支持动态帧率上限与隐藏停帧
- **自研压缩流水线**：词法级 JS 压缩（正确区分字符串/模板串/正则/注释，保留换行防 ASI 断句）、CSS 压缩、`CompressionStream` gzip，逐块语法校验失败即回退原文
- **自研 ZIP 实现**：更新包与卡面资源包使用（EOCD → 中央目录 → STORE/DEFLATE）
- **自制控件**：日历与取色器全部自研，并在 `document` 捕获阶段拦截原生 `type=color`/`type=date`，避免弹出系统原生选择器
- **无障碍**：`aria-*` 属性、跳转链接、`prefers-reduced-motion` 适配（13~14 处媒体查询）
- **响应式**：35~39 段媒体查询，断点覆盖 600/620/768/860/900/920/1025/1180 px；触屏设备自动移除 `backdrop-filter` 并放大触控目标

## 十三、为什么 OTTO版 比 精简版 大 1.3 MB

差异拆解（共 +1,321,136 字节）：

```
+1,321,136 B (100%)
├── +1,046,052 B  内嵌 base64 素材（79.2%）  ← 主要原因
└──   +275,216 B  CSS / JS / HTML 代码（20.8%）
```

**新增的 22 张图片全部是 WebP**，没有任何字体或第三方库（下表为**解码后**的图片实际体积）：

| 素材 | 数量 | 解码后体积 | 占比 |
|---|---|---|---|
| 邦多利乐队队标 | 8 | 约 133 KB | 9% |
| 邦多利乐队舞台背景 | 8 | 约 363 KB（最大单张约 152 KB） | 24% |
| 世界计划组合标志 | 6 | 约 271 KB | 18% |
| 应用图标（与精简版相同的重复图标） | 5 | 约 358 KB | 23% |
| **合计** | **27** | **约 1.10 MB** | **74%** |

为便于核对单位：上表是**解码后**的图片字节数；这些图片在文件里以 base64 文本存放，**在文件体积中约占 1.46 MB**（base64 会使数据膨胀约 4/3）。

**代码侧**增加的约 275 KB 主要来自：7 套品牌主题的 CSS（邦多利、P3、世界计划、重返未来1999、终末地夜间、明日方舟、苹果等）与特效规则，以及 **OTTO版独有的 74 个函数**——邦多利 + 世界计划共 41 个、资源包与自研 ZIP 18 个、视频/GIF 背景 10 个、GPU 探测、卡面立绘与白名单、多图背景等。

**「需 Win10+」的技术实因**：OTTO版大量使用 `color-mix()`（519 次）、`backdrop-filter`（124 次）、`:has()`（65 次）以及 `CompressionStream`/`DecompressionStream`（用于 gzip 与 ZIP 解压），并且**没有**精简版那段 ES5 兼容垫片。

## 十五、一句话总结

> **ENcwork** 是一个零构建、零框架、纯本地的教室大屏作业看板：把各科作业、考勤、考试与节假日倒计时集中到一屏，数据只存在本机、不上传，支持 5 套（精简版）到 23 套（OTTO版）主题、一键备份迁移与两版数据互通。
>
> **精简版**为 Win7 / 老电脑而生，牺牲装饰性特效换取兼容与轻量；
**OTTO版**为 Win10+ 而生，提供游戏联动主题、卡面资源包、视频背景与完整特效系统。
