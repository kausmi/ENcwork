# ENcwork · 月行水上

教室里那块大屏的作业板。

一个 `.html` 文件，双击就能用。作业、考勤、考试倒计时、节假日、时钟放一屏上，数据全都存在自己的浏览器里，不联网也不上传。

## 能干什么

**作业**
点学科卡片写，`Ctrl + Enter` 存。支持 Markdown、快捷词、模板、图片、标签、完成标记。内容边写边自动存草稿，手滑关掉也不丢。

**考勤**
点卡片点名，出勤 / 迟到 / 请假 / 缺勤四种状态，名字和颜色能自己改。名单可以整班粘进去，点名框支持中文、全拼、首字母搜（打 `zs` 出张三）。有周报月报，能导 CSV 和 PNG。

**倒计时**
考试时间表、节假日、周末，都能自定义。倒计时精度可以只显示天数，也可以到分。

**考试看板**
单独一个全屏界面，不占主界面。大字时钟 + 当前科目 + 考试时间范围，四种样式可选，其中「影院」是深底单列、时钟能显示到毫秒。字号能用滑杆拉，拉到哪都按一个区间自动收，不会把下面的按钮顶出去。

**其他零碎**
通知公告、作业历史、作业量统计、学习热力图、本地快照（最多留 10 份可回滚）、数据体检、导出 JSON / MD / UAF(PDF)、自动备份到文件夹、截图（snapdom 优先，失败退回 html2canvas）。

**问 AI**
不需要 API Key。选好数据范围，它把统计口径整理成一段提示词，复制到豆包 / ChatGPT / Claude 那边问就行。

## 两个版本的字面区别

精简版不是 OTTO 版砍几个功能，是专门给老机器做的一版：

- 内嵌一段纯 ES5 垫片，去掉了全部可选链语法，旧版 Edge（EdgeHTML）不会整段脚本报错
- 给不支持 `color-mix()`、`inset`、`flex gap`、`backdrop-filter` 的浏览器准备了静态色回退
- 液态玻璃、边缘高光、粒子这些装饰特效直接换成空函数，只留性能分析器做诊断
- 只剩 5 套 Material 主题

OTTO 版这边多了邦多利（8 支乐队）、世界计划（6 个组合）、P3R / P5R / 重返未来 1999 / 明日方舟 / 终末地这些联动主题，卡面资源包、视频与 GIF 背景、GPU 分级降级、动效系统也都在。队标和舞台背景是内嵌的 WebP，不请求网络。

两版共用同一个 localStorage 键（`homework_board_v5`），所以能一键互相搬数据：设置 → 反馈与帮助 → 数据迁移，先导出到中转槽位，再在另一个版本里导入。全程不联网、不落中间文件。

## 技术上是怎么堆起来的

没有框架，没有打包器，没有构建流程。整个东西就是一个 HTML 文件，CSS 和 JS 全在里面。

| 依赖 | 用途 |
|---|---|
| `pinyin-pro` 3.27.0 | 名单拼音搜索 |
| `@zumer/snapdom` 3.1.0 | 截图，首选 |
| `html2canvas` 1.4.1 | 截图回退、UAF 渲染 |
| `jspdf` 2.5.2 | UAF PDF 导出 |
| `pdfjs-dist` 4.2.67 | UAF PDF 导入解析 |

全都有运行时存在性检查，缺了会自己降级（截图退 html2canvas，拼音退纯文本匹配，PDF 相关提示加载中）。

数据在 localStorage（主键 `homework_board_v5`）和 IndexedDB（背景图、作业图片、快照、卡面资源包）两处。保存走 300 毫秒防抖，关页面和切后台时强制刷一次。

几个自己觉得还行的部分：

- 瀑布流是 Flex 列 + LPT 贪心分列 + 二次平衡，测量高度时临时关掉 `content-visibility`，量出来的数是真的
- 卡片不再按张数分档，超出可视范围就跳过绘制，滚到那儿才渲染
- Markdown 渲染塞进 Blob Worker 后台跑，500 字以上才预热，结果和主线程一致
- 每分钟看一眼 JS 堆，超 70% 清轻缓存，超 85% 清深缓存，用户数据一个字节都不碰
- 更新数据包和卡面资源包用的是自己写的最小 ZIP 解析（EOCD → 中央目录 → STORE/DEFLATE）
- 日历和取色器都是自己画的，还在 `document` 捕获阶段拦掉了原生的 `type=color` / `type=date`

## 用的时候可能会遇到的

**数据在哪**
只在你这台电脑的这个浏览器里。清浏览器数据就没了，换电脑也不会跟过去。养成定期导 JSON 备份的习惯，别等丢了才想起来。

**自动备份**
需要 Chrome / Edge 的文件夹授权。没授权的话会退回普通下载，能用，就是每次弹一下。

**截图报错**
先把控制台报错发出来。截图链路依赖 CDN 上的 snapdom 和 html2canvas，网络被拦或两个都没加载成功时会失败——这种情况多半是网络问题，不是文件坏了。

**发现 bug**
提 [Issue](https://github.com/kausmi/ENcwork/issues)，最好带上浏览器版本和报错原文。设置 → 其他里有「运行错误日志」，能一键复制完整堆栈，比自己描述有用得多。
