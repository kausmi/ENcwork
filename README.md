# ENcwork · E课作业

专为晚自习场景打造的教室大屏作业展示板。各科作业、考勤人数、考试与节假日倒计时一屏尽览，
学生抬头即看；数据本地保存，不联网也能用。

## 两个版本

| 文件 | 版本 | 说明 |
|---|---|---|
| `ENcwork-otto.html` | 完整版 | 24 套主题（含邦多利 / 世界计划 / Our Notes / 终末地 等），完整特效与插件系统 |
| `ENcwork-legacy.html` | 精简版 | 仅 5 套 Material 基础主题，体积更小，CSS 兼容老内核（Win10 以下 / 低版本 IE 内核） |

两个文件都是**单文件应用**：样式、脚本、字体图标、截图引擎（snapdom 3.1.0 + html2canvas 1.4.1）
全部内嵌，双击即可在浏览器中打开，无需服务器、无需安装、断网可用。

## 使用方法

1. 下载对应版本的 `.html` 文件；
2. 双击用浏览器打开（推荐 Chrome / Edge / 新版 Firefox）；
3. 数据保存在浏览器本地存储（localStorage），建议定期在「设置 → 数据管理」里导出备份。

> 换浏览器、换设备、清理浏览器数据后本地数据会丢失，请务必用「数据管理」里的导出功能备份。

## 主要功能

- **作业卡片**：按科目分组，支持富文本 / Markdown、草稿自动保存、智能分割多条作业
- **考勤卡片**：应到 / 实到 / 缺席名单，支持自定义考勤状态与分组、沿用上一次记录
- **考试倒计时 / 节假日倒计时**
- **AI 智能分析**：接入 OpenAI 兼容 API，分析作业量与完成情况（可选择性排除科目）
- **作业量统计**：按科目统计项数 / 涉及天数 / 日均 / 占比，可导出 CSV
- **多主题**：24 套完整主题，含毛玻璃 4.0 与液态玻璃质感
- **背景**：自定义图片、多图轮播、轮播预设、智能边缘取色、拖动裁切
- **快捷栏**：完全自定义按钮显隐、顺序、分隔线、标签文字
- **截图**：普通截图 / 特效截图，可导出图片或 PDF
- **数据管理**：本地备份、导入导出、JSON / HTML / PDF 导出
